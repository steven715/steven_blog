## 決策權歸屬

| 決策類型 | 歸屬 | 說明 |
|----------|------|------|
| 架構選型 | 人類 | 技術棧、系統邊界、通訊協議 |
| API 契約 | 人類 | 介面定義、錯誤碼語意 |
| 安全邊界 | 人類 | 鎖策略選擇、權限模型 |
| 實作細節 | AI | 在約束內完成具體編碼 |
| 測試生成 | AI | 依標準產出測試，人類審查語義斷言 |
| 文件初稿 | AI | 產出結構化初稿，人類校準內容準確性 |
| 設計 Review | 共同 | AI 提出方案，人類判斷取捨 |
| Edge case 分析 | 共同 | AI 列舉可能性，人類判斷業務合理性 |

## 驗收閘門

AI 的每一類產出，人類用以下標準驗收：

- **代碼**：通過 review-checklist + 所有測試通過 + 無 sanitizer 警告
- **測試**：覆蓋邊界條件 + 語義斷言 + 不只測 happy path
- **文件**：內容準確 + 與代碼一致 + 非 AI 也能理解

## 核心原則

- AI 是實作者，人類是決策者與審查者。
- 約束寫在文件裡，而非每次口頭重複。文件化的約束可被審視、可被迭代。
- 當 AI 產出品質下降時，優先檢查約束是否充分，而非直接修改產出。
