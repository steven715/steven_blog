## 代碼 Review

- [ ] 每個函數只做一件事，且名稱能準確描述其行為
- [ ] 沒有未處理的錯誤路徑
- [ ] 共享狀態的鎖策略已標明且合理
- [ ] 沒有 magic numbers
- [ ] 新增的公開 API 有對應的測試

## 測試 Review

- [ ] 每個測試有至少一個語義斷言（非僅技術行為驗證）
- [ ] 覆蓋了主要的邊界條件，而非只有 happy path
- [ ] 測試可獨立運行，無順序依賴
- [ ] 測試命名清晰表達了被測場景

## 文件 Review

- [ ] 新增的模組有對應的職責描述
- [ ] 架構決策有 ADR 記錄
- [ ] 變更影響到的互動圖已同步更新
